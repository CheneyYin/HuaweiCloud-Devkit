# Huawei Cloud AgentArts (智果)

**STOP - Do not answer from general knowledge.** AgentArts is newer than most training data. Follow this routing layer; measured facts live in the tier map and traps below.

## What AgentArts Is

Enterprise agent platform for Huawei Cloud: hosts agent runtimes (LangGraph/LangChain/custom code), memory spaces, agent gateway, cloud runtime operations (command execution, file transfer, sessions), a cloud browser (isolated, agent-drivable browser sessions with a domain fence), and a cloud code interpreter (an isolated, agent-drivable python sandbox: execute code, install packages, transfer files — environments are disposable and the local machine is never touched). Product overview and usage modes: https://support.huaweicloud.com/productdesc-agentarts/agentarts_03_0002.html

## Prerequisites

- Python 3.10+ (per the SDK README) and `pip install agentarts-sdk==0.1.10 -i https://mirrors.huaweicloud.com/repository/pypi/simple` (pinned; Huawei Cloud PyPI mirror — if the mirror lags a newly pinned version, drop `-i` and install from official PyPI; verify with `agentarts --version`). Or run `npx huaweicloud-devkit install-agentarts` (devkit-owned venv, auto-resolved). CLI resolution: `AGENTARTS_BIN` > devkit-managed venv > PATH — a personal venv install needs its full path or `AGENTARTS_BIN`.
- Credentials: `HUAWEICLOUD_SDK_AK` / `HUAWEICLOUD_SDK_SK` env vars. NEVER let AK/SK enter shell history or the conversation — see huaweicloud-cli-and-auth
- Region: control plane is cn-southwest-2 only. The memory six (create/get/list/update/delete/status) CLAIM a cn-north-4 default in help text — the actual code fallback is cn-southwest-2 (constant.py:79, trap 15); an exported HUAWEICLOUD_SDK_REGION/HUAWEICLOUD_REGION/OS_REGION_NAME wins first in your own terminal (wrapper child envs strip them). Pass `--region` explicitly on the six regardless (install/uninstall take no region flag)

## MCP Tools

- `huaweicloud_agentarts_plan_cli_command` — classify + canonicalize (per-operation flags: `--yes`/`--force`/`--output json` where measured-safe) without executing; returns the approval token for approved-tier writes; rejects `memory create` missing `--strategies` (server-side 400 + orphan API key — the error lists the legal values)
- `huaweicloud_agentarts_run_readonly_command` — read-only execution with runtime credential injection and output redaction
- `huaweicloud_agentarts_run_approved_command` — approved-tier execution bound to the plan's exact args and token
- `huaweicloud_agentarts_list_agents` — read-only agent runtime listing via the SDK Python API (0.1.10 has no list CLI command); region defaults to cn-southwest-2, optional agent_name fuzzy filter, omit limit/offset to keep SDK pagination defaults
- `huaweicloud_agentarts_memory_read` — read the memory DATA plane via the SDK (0.1.10 CLI has no data-plane subcommands): sessions, messages, memories, semantic search. One-time data-plane api_key is read from the wrapper-captured 0600 key file (only spaces created through `memory create` have one) and injected env-only. actor_id is REQUIRED for search_memories (server isolation is actor-level), optional on list_sessions/list_memories (omitting lists every actor — the result carries a note). list_messages requires session_id (the space-wide form builds a broken path in 0.1.10). search_memories returns the WHOLE space ranked — no default min_score cutoff, and a set min_score is applied client-side by the bridge (the server-side filter is measured-ineffective); judge hits by the returned searchSummary score range, not result presence; its page size is filters.top_k, not limit
- `huaweicloud_agentarts_memory_plan` / `huaweicloud_agentarts_memory_write` — the data-plane WRITE pair (create_session, add_messages batch, delete_session soft, delete_memory irreversible, delete_memories batch irreversible — ONE approval covers the whole id array), token-gated like every approved cloud write: plan validates and mints a token bound to the exact request, write consumes it single-use. add_messages extraction is async (a write is not immediately searchable). actor_id required for create_session; TextMessage roles user/assistant/system only. See references/cli-workflows.md for the write loop, retry semantics, the 7-day message TTL trap, and the bridge-vs-plugin dual-path decision

- `huaweicloud_agentarts_browser_read` — read the browser CONTROL plane via the SDK (list/get browsers and profiles). auth_type matters when picking a browser to drive: IAM-typed (the create tool's default) signs the data plane with the same injected AK/SK; API_KEY-typed needs the console api_key (see trap table)
- `huaweicloud_agentarts_browser_plan` / `huaweicloud_agentarts_browser_write` — the browser WRITE pair: control-plane resource lifecycle (create/update/delete browser + profiles; deletes irreversible) AND data-plane session lifecycle (start_session — one approval starts the session AND its lease: the domain fence and timeout shown are what the cloud enforces; save_profile; update_stream — enabled re-arms the agent after a human handoff). start records the 0600 session state file (the lease); the orphan guard blocks a second start on a live lease
- `huaweicloud_agentarts_browser_session` — free-tier session ops on a recorded lease: get_session, stop_session (cleanup; deletes the lease record), take_control (human handoff — page state preserved)
- `huaweicloud_agentarts_browser_invoke` — all 18 browser actions, lease-gated (not token-gated). TWO detection rules the envelope cannot do for you: the domain fence blocks at page-load with is_error still FALSE (watch current_url for chrome-error://chromewebdata/) and the envelope's own is_error bit. Screenshots decode to 0600 files — the result carries the path, never the base64
- `huaweicloud_agentarts_interpreter_read` — read the interpreter CONTROL plane via the SDK (list/get interpreters). list items carry NO auth_type — get_code_interpreter is the only read that proves the auth posture; get before driving a resource you did not create through this toolkit
- `huaweicloud_agentarts_interpreter_plan` / `huaweicloud_agentarts_interpreter_write` — the interpreter WRITE pair: resource lifecycle (create/update/delete — deletes irreversible and CASCADE to sessions) AND data-plane session start (one approval starts the session AND its lease: the 0600 record is the consent boundary, while the cloud session dies independently and is measured NOT a wall clock — trap 85). The orphan guard blocks a second start on a live lease
- `huaweicloud_agentarts_interpreter_session` — free-tier session ops on a recorded lease: get_session, stop_session (cleanup; deletes the lease record — on success AND on a confirmed death signature, so a dead session never lockouts the re-start). Both stay reachable past local lease expiry (stop is the only deterministic cleanup)
- `huaweicloud_agentarts_interpreter_invoke` — the FIVE sandbox actions (execute_code / install_packages / upload_files / download_file / clear_context), lease-gated. The sandbox is an IPython kernel (variables persist; is_error true means the REMOTE python raised, not a bridge failure). Package version specs are `==` only — the sandbox shell interprets `>` forms as redirection and newline package names as second commands, both with exit_code 0. Binary downloads decode to 0600 files; the base64 never rides the payload

See references/cli-workflows.md for the golden path and the full trap list, references/credentials.md for secret injection and the build-context leak, and references/langchain-maas-runbook.md for a worked LangChain + MaaS deploy (mirror-first, mainland-China).

## Hard Rules

- **Mirror-first (mainland-China default).** Pull Docker base images through a mirror (`docker.m.daocloud.io`) and retag to the canonical name; install/point pip at the Huawei Cloud mirror (`https://mirrors.huaweicloud.com/repository/pypi/simple`, fallback `https://repo.huaweicloud.com/...` on `429`). Fall back to docker.io/pypi.org only when a mirror is unavailable. See `references/cli-workflows.md` for the pre-warm recipe.
- **Keep `launch` inside the MCP client timeout (~300s).** `launch` builds on the local Docker daemon; a China-network build without pre-warming (base image + pip mirror + `.dockerignore`) can exceed the timeout, returning JSON-RPC `-32001` with lost output and an orphaned build container. Pre-warm first; treat `-32001` as "build too slow", check `docker ps -a` for an orphan and clean it up.
- **Never place a secret in a file inside the build context.** `COPY . .` bakes it into the image and `launch` pushes that image to SWR. Exclude `.agentarts_config.yaml` (and helper scripts) via `.dockerignore`; the runtime receives env vars from the CLI's YAML, not from the image. See `references/credentials.md`.
- `--bearer-token`/`-bt` on ANY command is forbidden — argv is process-list visible. Env-var auth only.
- The CLI can FAIL with exit code 0 (prints a traceback, still exits 0). Parse output, never trust exit codes.
- First run of any agentarts command writes `~/.bashrc`, `~/.bash_completions/`, `~/.agentarts/.completion_shown`, and `~/.huaweicloud/application_id` (a telemetry UUID sent in every request's User-Agent). Warn the user before first use.
- `memory install` persists credentials into the host agent's own config (e.g. `~/.hermes/.env` API key plus a config rewrite); per the SDK repo the plugin adds session capture and reply tracking to the host agent. A user decision — run in the user's terminal, never agent-initiated.
- Auth chain is env → `~/.huaweicloud/credentials` profile → metadata: without env vars the CLI may silently authenticate from a profile file. Credentials must come from explicit injection only.
